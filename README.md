# pfa-week010
Research Proposal
I want to create a Temple Run-inspired game in Unreal Engine, but with an Arabian theme featuring different environments and levels inspired by Arabian architecture and landscapes as well as mythology.
I have never created a game in Unreal Engine before and I think this project would be a great opportunity to learn. I personally find Unreal Engine a little complicated, especially when it comes to game design. I want to become more comfortable navigating the software and create interactive environments. I also think these skills would help me in my other classes and allow me to use Unreal Engine more confidently for both games and filmmaking in the future.
I plan to show a playable version of the game. If I end up creating any useful tools or systems along the way, I would also like to demonstrate those.

November 10: Have the main environment ready, including the overall aesthetic, atmosphere, and sound design.

November 17: Have a playable character with basic movement mechanics and hopefully multiple levels or environments created.

November 23: Focus on playtesting, fixing bugs and polishing the overall experience.

If I cannot complete everything I planned, I would still like to present at least one fully playable level. Even if the visuals are not as detailed or stylized as I originally imagined, I want the basic gameplay to work. And I think the biggest challenge will be creating and connecting the different levels. I am still unsure how I want the transitions between environments to work or how each level will differ in terms of gameplay and design. I also expect learning the game mechanics in Unreal Engine to take some time, since this is my first time creating a game in the software.
